# 映想 · 官方下载

本仓库仅分发映想 Windows x64 安装包、免安装版和更新说明，不包含应用源码。

请从 [GitHub Releases](https://github.com/Y-Heng/imagine-releases/releases) 下载：

- `Imagine-<版本>-windows-x64-setup.exe`：中文安装包。
- `Imagine-<版本>.exe`：免安装版，需要 Microsoft Edge WebView2 Runtime。

从 1.6.0 或更早版本升级时，请先从本页手动下载一次。1.6.1 起可在「设置 → 版本信息」检查更新。免安装版不会原地替换。
